# Contributing Guidelines

1. **Branch:** Create a feature branch (`feat/your-feature`, `fix/your-bug`).
2. **Code Style:** Run `pnpm lint` and `pnpm format:check` before committing.
3. **Tests:** Add/modify tests for your changes.
4. **Commit:** Use [Conventional Commits](https://www.conventionalcommits.org/).

## Code Standards

- TypeScript for all code
- SCSS modules for styling
- Mobile-first, accessible components
- Internationalization support for UI
- All UI components documented in Storybook
